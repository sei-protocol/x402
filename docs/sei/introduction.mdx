## Sei's Advantages for x402

<AccordionGroup>
  <Accordion title="Optimistic Parallelization" icon="parallel">
    **Concurrent transaction processing**

    Unlike other blockchains that process transactions sequentially, Sei's optimistic parallelization allows multiple non-conflicting transactions to be processed simultaneously. This means your x402 payments can be processed in parallel with other blockchain activity, reducing latency and increasing throughput.

    ```javascript
    // Multiple payments can be processed simultaneously
    const payments = await Promise.all([
      client.pay('/api/data-feed'),
      client.pay('/api/ai-inference'),
      client.pay('/api/image-generation')
    ]);
    ```
  </Accordion>

  <Accordion title="Native Order Matching" icon="exchange">
    **Built-in trading infrastructure**

    Sei's native order book enables sophisticated payment routing and automatic token swaps. Your x402 system can accept payments in various tokens and automatically convert them to your preferred settlement currency.

    ```javascript
    // Accept payments in multiple tokens
    const facilitator = createFacilitator({
      network: 'sei',
      acceptedTokens: ['SEI', 'USDC', 'WETH'],
      settlementToken: 'USDC'
    });
    ```
  </Accordion>

  <Accordion title="Market-Based Fee Mechanism" icon="chart-line">
    **Predictable and fair pricing**

    Sei's fee mechanism prevents sudden spikes in gas costs, ensuring your micropayment costs remain predictable. This is crucial for x402 systems where payment amounts might be small.
  </Accordion>
</AccordionGroup>

## Sei-Specific Features in x402

x402 takes advantage of several Sei-specific features to optimize micropayment performance:

### 1. Fast Finality for Real-time APIs

```javascript
// Stream real-time data with per-update payments
app.get(
  "/api/live-prices",
  facilitator.middleware({
    scheme: "streaming",
    pricePerSecond: "0.001", // 0.001 SEI per second of data
  }),
  (req, res) => {
    // Sei's 400ms finality enables real-time payment verification
    const priceStream = createPriceStream();
    res.writeHead(200, { "Content-Type": "application/json" });

    priceStream.on("data", (price) => {
      res.write(JSON.stringify(price) + "\n");
    });
  }
);
```

### 2. Multi-Token Payment Support

```javascript
// Accept payments in SEI, USDC, or wrapped tokens
const facilitator = createFacilitator({
  network: "sei",
  paymentTokens: [
    { symbol: "SEI", address: "native", decimals: 18 },
    { symbol: "USDC", address: "0x...", decimals: 6 },
    { symbol: "WSEI", address: "0x...", decimals: 18 },
  ],
  preferredToken: "USDC",
});
```

### 3. Gas Optimization

```javascript
// Batch payments for efficiency
const client = createClient({
  network: "sei",
  batchPayments: true,
  maxBatchSize: 10, // Batch up to 10 payments
  batchTimeout: 1000, // Or every 1 second
});
```
