# Make Your First Payment

This guide walks you through creating a complete payment flow on Sei Network - from setting up a paid endpoint to successfully processing your first micropayment.

<Info>
  **What you'll build:** A simple paid API endpoint that requires 0.01 SEI per
  request, and a client that automatically handles the payment.
</Info>

## Project Setup

<Steps>
  <Step title="Create project structure">

## Build the Payment Server

Create a server that requires payment for premium content:

<CodeGroup>
```typescript src/server.ts
import express from 'express';
import { createFacilitator } from '@sei-js/x402-facilitator';
import dotenv from 'dotenv';

dotenv.config();

const app = express();
const PORT = process.env.PORT || 3000;

// Create X402 facilitator for Sei testnet
const facilitator = createFacilitator({
network: process.env.NETWORK as 'sei-testnet',
scheme: 'exact',
price: process.env.API_PRICE || '0.01',
currency: 'SEI'
});

// Public endpoint (no payment required)
app.get('/api/public', (req, res) => {
res.json({
message: 'This is free public data',
timestamp: new Date().toISOString(),
data: {
publicInfo: 'Available to everyone',
freeData: 42
}
});
});

// Premium endpoint (requires payment)
app.get('/api/premium', facilitator.middleware(), (req, res) => {
res.json({
message: 'Premium data unlocked!',
timestamp: new Date().toISOString(),
data: {
secretValue: 'This data costs 0.01 SEI',
premiumMetrics: {
revenue: 15420.50,
users: 3847,
growth: '+23.4%'
},
prediction: 'Market will trend upward'
}
});
});

// Payment status endpoint
app.get('/api/status', (req, res) => {
res.json({
server: 'X402 Payment Server',
network: process.env.NETWORK,
price: `${process.env.API_PRICE} SEI`,
endpoints: {
public: '/api/public (free)',
premium: '/api/premium (0.01 SEI)',
status: '/api/status (free)'
}
});
});

app.listen(PORT, () => {
console.log(`🚀 X402 Payment Server running on http://localhost:${PORT}`);
console.log(`💰 Premium endpoint: /api/premium (${process.env.API_PRICE} SEI)`);
console.log(`🆓 Public endpoint: /api/public (free)`);
console.log(`📊 Status: /api/status`);
console.log('\n🧪 Test with: curl http://localhost:3000/api/premium');
});

````
</CodeGroup>

## Build the Payment Client

Create a client that can make paid requests:

<CodeGroup>
```typescript src/client.ts
import { createClient } from '@sei-js/x402-client';
import dotenv from 'dotenv';

dotenv.config();

async function demonstratePayments() {
  console.log('🔄 Initializing X402 client for Sei testnet...\n');

  try {
    // Create X402 client
    const client = createClient({
      network: process.env.NETWORK as 'sei-testnet',
      privateKey: process.env.PRIVATE_KEY!
    });

    // Check wallet balance
    console.log('💰 Checking wallet balance...');
    const balance = await client.getBalance();
    console.log(`   Balance: ${balance} SEI\n`);

    if (parseFloat(balance) < 0.05) {
      console.log('⚠️  Low balance! Get test SEI from: https://faucet.sei.io\n');
    }

    // Test free endpoint first
    console.log('🆓 Testing free endpoint...');
    const freeResponse = await fetch('http://localhost:3000/api/public');
    const freeData = await freeResponse.json();
    console.log('✅ Free endpoint response:', freeData.message);
    console.log('   Data:', freeData.data, '\n');

    // Try premium endpoint without payment (should fail)
    console.log('❌ Testing premium endpoint without payment...');
    const unpaidResponse = await fetch('http://localhost:3000/api/premium');
    if (unpaidResponse.status === 402) {
      console.log('✅ Payment required (as expected)');
      console.log('   Status:', unpaidResponse.status, unpaidResponse.statusText, '\n');
    }

    // Make paid request to premium endpoint
    console.log('💳 Making paid request to premium endpoint...');
    const paidResponse = await client.request('http://localhost:3000/api/premium');
    console.log('✅ Payment successful!');
    console.log('   Response:', paidResponse.data.message);
    console.log('   Premium data:', paidResponse.data.data, '\n');

    // Check final balance
    const finalBalance = await client.getBalance();
    const spent = parseFloat(balance) - parseFloat(finalBalance);
    console.log('💰 Final balance:', finalBalance, 'SEI');
    console.log(`💸 Amount spent: ~${spent.toFixed(4)} SEI`);
    console.log('\n🎉 First X402 payment completed successfully!');

  } catch (error) {
    console.error('❌ Error:', error.message);
    console.log('\n🔧 Troubleshooting:');
    console.log('   1. Make sure the server is running: npm run dev:server');
    console.log('   2. Check your wallet has test SEI: https://faucet.sei.io');
    console.log('   3. Verify environment variables in .env file');
  }
}

demonstratePayments();
````

</CodeGroup>

## Understanding What Happened

Let's break down the payment flow:

<Accordion title="1. Payment Detection">
  When the client requests `/api/premium`, the X402 facilitator middleware: -
  Checks for a payment header in the request - Finds no payment, returns 402
  Payment Required - Includes payment details (amount, currency, network)
</Accordion>

<Accordion title="2. Payment Creation">
  The X402 client automatically: - Detects the 402 response - Creates a payment
  transaction on Sei testnet - Signs and submits the transaction - Waits for
  confirmation (usually ~400ms on Sei)
</Accordion>

<Accordion title="3. Payment Verification">
  The facilitator middleware: - Receives the retry request with payment header -
  Verifies the payment on Sei blockchain - Confirms the correct amount was paid
  to the correct address - Allows access to the protected content
</Accordion>

<Accordion title="4. Response Delivery">
  Once payment is verified: - The protected endpoint handler executes - Premium
  content is returned to the client - The payment is considered complete
</Accordion>

## Troubleshooting

<AccordionGroup>
  <Accordion title="Payment fails with insufficient funds">
    **Problem:** Client shows balance but payment still fails **Solution:** -
    Ensure you have enough SEI for both the payment amount AND gas fees - Try
    with a higher balance (request more from faucet) - Check you're on the
    correct network (testnet vs mainnet)
  </Accordion>

{" "}

<Accordion title="Server doesn't detect payment">
  **Problem:** Payment goes through but server still returns 402 **Solution:** -
  Verify server and client are using the same network - Check the facilitator
  address matches your wallet - Wait for transaction confirmation (up to 1-2
  seconds on Sei)
</Accordion>

  <Accordion title="Connection errors">
    **Problem:** RPC connection failures or timeouts **Solution:** - Verify RPC
    URL is correct for testnet - Check firewall/proxy settings - Try alternative
    RPC endpoints from Sei documentation
  </Accordion>
</AccordionGroup>
