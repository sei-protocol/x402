# Development Environment Setup

Get your development environment ready for building x402 applications on Sei Network. This guide covers wallet setup, network configuration, and essential tools.

## Prerequisites

<AccordionGroup>
  <Accordion title="Node.js Environment" icon="node-js">
    **Required versions and tools:**
    - **Node.js** v18+ - [Download from nodejs.org](https://nodejs.org)
    - **npm**, **yarn**, or **pnpm** - Package manager of choice
    - **Git** - For cloning repositories and version control
    
    <Check>
    Verify installation: `node --version && npm --version`
    </Check>
  </Accordion>

  <Accordion title="Code Editor" icon="code">
    **Recommended editors with TypeScript support:**
    - **VS Code** - Free, excellent TypeScript integration
    - **Cursor** - AI-powered VS Code fork
    - **WebStorm** - Full-featured IDE from JetBrains
    
    <Tip>
    Install TypeScript and Solidity extensions for the best development experience.
    </Tip>
  </Accordion>
</AccordionGroup>

## Wallet Configuration

<Steps>
  <Step title="Install a Compatible Wallet">
    Choose and install a wallet that supports Sei Network:
    
    <Tabs>
      <Tab title="MetaMask">
        **Most popular option - works everywhere**
        
        1. Install [MetaMask browser extension](https://metamask.io)
        2. Create a new wallet or import existing one
        3. Secure your seed phrase safely
        
        <Check>MetaMask installed and wallet created</Check>
      </Tab>
      
      <Tab title="Compass Wallet">
        **Native Sei wallet with advanced features**
        
        1. Install [Compass Wallet](https://compasswallet.io)
        2. Create new wallet or import from seed phrase
        3. Enable developer mode in settings
        
        <Check>Compass wallet ready and configured</Check>
      </Tab>
      
      <Tab title="Keplr">
        **Multi-chain wallet with Sei support**
        
        1. Install [Keplr browser extension](https://www.keplr.app)
        2. Create wallet and add Sei network
                 3. Switch to EVM mode for x402 compatibility
         
         <Check>Keplr configured for Sei EVM</Check>
      </Tab>
    </Tabs>
  </Step>

    Configure your wallet to connect to Sei networks:

        3. Approve the network addition in your wallet

## Development Tools Setup

<Steps>
  <Step title="Install X402 Packages">
    Set up a new project with X402 dependencies:
    
    <CodeGroup>
      ```bash npm
      # Create new project
      mkdir sei-x402-project && cd sei-x402-project
      npm init -y
      
      # Install core x402 packages
      npm install @x402/client @x402/facilitator
      
      # Install framework-specific packages (choose one)
      npm install @x402/express  # For Express.js
      npm install @x402/next     # For Next.js
      npm install @x402/hono     # For Hono
      ```
      
      ```bash yarn
      # Create new project
      mkdir sei-x402-project && cd sei-x402-project
      yarn init -y
      
      # Install core x402 packages
      yarn add @x402/client @x402/facilitator
      
      # Install framework-specific packages (choose one)
      yarn add @x402/express     # For Express.js
      yarn add @x402/next        # For Next.js
      yarn add @x402/hono        # For Hono
      ```
      
      ```bash pnpm
      # Create new project
      mkdir sei-x402-project && cd sei-x402-project
      pnpm init -y
      
      # Install core x402 packages
      pnpm add @x402/client @x402/facilitator
      
      # Install framework-specific packages (choose one)
      pnpm add @x402/express     # For Express.js
      pnpm add @x402/next        # For Next.js
      pnpm add @x402/hono        # For Hono
      ```
    </CodeGroup>
    
    <Check>x402 packages installed successfully</Check>
  </Step>

  <Step title="Configure TypeScript">
    Set up TypeScript for better development experience:
    
    ```bash
    # Install TypeScript and related tools
    npm install -D typescript @types/node ts-node nodemon
    
    # Initialize TypeScript configuration
    npx tsc --init
    ```
    
    Update `tsconfig.json` with Sei-optimized settings:
    
    ```json
    {
      "compilerOptions": {
        "target": "ES2022",
        "module": "commonjs",
        "lib": ["ES2022"],
        "allowJs": true,
        "outDir": "./dist",
        "strict": true,
        "esModuleInterop": true,
        "skipLibCheck": true,
        "forceConsistentCasingInFileNames": true,
        "resolveJsonModule": true
      },
      "include": ["src/**/*"],
      "exclude": ["node_modules", "dist"]
    }
    ```
    
    <Check>TypeScript configured for x402 development</Check>
  </Step>

  <Step title="Create Environment Configuration">
    Set up environment variables for network configuration:
    
    Create `.env` file:
    ```bash
    # Sei Network Configuration
    SEI_NETWORK=sei-testnet
    SEI_RPC_URL=https://evm-rpc-testnet.sei-apis.com
    SEI_CHAIN_ID=713715
    
    # Development Wallet (use a test wallet only!)
    PRIVATE_KEY=your_test_wallet_private_key_here
    
    # x402 Configuration
    x402_FACILITATOR_ADDRESS=your_wallet_address_here
    x402_DEFAULT_PRICE=0.01
    ```
    
    <Warning>
    **Security Warning:** Never commit private keys to version control. Use test wallets only for development.
    </Warning>
    
    Add `.env` to your `.gitignore`:
    ```bash
    echo ".env" >> .gitignore
    ```
    
    <Check>Environment variables configured securely</Check>
  </Step>
</Steps>

## Verify Setup

Test your development environment with a simple verification script:

<CodeGroup>
```typescript TypeScript
// verify-setup.ts
import { createClient } from '@x402/client';
import { createFacilitator } from '@x402/facilitator';
import * as dotenv from 'dotenv';

dotenv.config();

async function verifySetup() {
console.log('🔍 Verifying X402 setup on Sei...\n');

try {
// Test client connection
const client = createClient({
network: 'sei-testnet',
privateKey: process.env.PRIVATE_KEY
});

    const balance = await client.getBalance();
    console.log('✅ Client connected successfully');
    console.log(`💰 Wallet balance: ${balance} SEI\n`);

    // Test facilitator configuration
    const facilitator = createFacilitator({
      network: 'sei-testnet',
      scheme: 'exact',
      price: '0.01'
    });

    console.log('✅ Facilitator configured successfully');
    console.log('🎉 Your X402 development environment is ready!\n');

    if (parseFloat(balance) < 0.1) {
      console.log('⚠️  Low balance detected. Get more test SEI from:');
      console.log('   https://faucet.sei.io');
    }

} catch (error) {
console.error('❌ Setup verification failed:', error.message);
console.log('\n📖 Check the setup guide: /sei/setup');
}
}

verifySetup();

````

## Common Setup Issues

<AccordionGroup>
  <Accordion title="Network connection failures">
    **Symptoms:** RPC connection errors, timeout exceptions
    
    **Solutions:**
    - Verify RPC URL is correct for your target network
    - Check firewall settings aren't blocking connections
    - Try alternative RPC endpoints from [Sei documentation](https://docs.sei.io)
    
    ```javascript
    // Test RPC connectivity
    const response = await fetch('https://evm-rpc-testnet.sei-apis.com', {
      method: 'POST',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({
        jsonrpc: '2.0',
        method: 'eth_blockNumber',
        params: [],
        id: 1
      })
    });
    ```
  </Accordion>
  
  <Accordion title="Wallet connection issues">
    **Symptoms:** Provider not found, wallet not detected
    
    **Solutions:**
    - Ensure wallet extension is installed and enabled
    - Refresh browser page after installing wallet
    - Check wallet is connected to correct network
    - Try connecting in incognito mode to test extension conflicts
  </Accordion>
  
  <Accordion title="Transaction failures">
    **Symptoms:** Out of gas, insufficient funds, nonce errors
    
    **Solutions:**
    - Check wallet has sufficient SEI for gas fees
    - Verify network configuration matches wallet network
    - Reset account in wallet settings if nonce is stuck
    - Use higher gas limits for complex transactions
  </Accordion>
</AccordionGroup>
