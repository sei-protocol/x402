## Express.js Integration

Easily add x402 payments to your Express.js server with the built-in middleware.

## Installation

```bash
npm install express @x402/facilitator @x402/express
```

## Basic Setup

```typescript
import express from "express";
import { createFacilitator } from "@x402/facilitator";
import { x402Middleware } from "@x402/express";

const app = express();

// Create facilitator instance
const facilitator = createFacilitator({
  network: "sei-mainnet",
  privateKey: process.env.FACILITATOR_PRIVATE_KEY,
});

// Apply x402 middleware
app.use(
  "/api/premium",
  x402Middleware(facilitator, {
    price: "0.01", // 0.01 SEI per request
  })
);

// Protected routes
app.get("/api/premium/data", (req, res) => {
  res.json({
    message: "This is premium data!",
    timestamp: new Date().toISOString(),
  });
});

app.listen(3000, () => {
  console.log("Server running on port 3000");
});
```

## Advanced Configuration

### Custom Pricing

```typescript
app.use(
  "/api/ai",
  x402Middleware(facilitator, {
    pricing: (req) => {
      const complexity = req.query.complexity || "simple";
      return {
        amount: complexity === "complex" ? "0.05" : "0.01",
        currency: "SEI",
      };
    },
  })
);
```

### Error Handling

```typescript
app.use(
  "/api/premium",
  x402Middleware(facilitator, {
    price: "0.01",
    onPaymentError: (error, req, res) => {
      res.status(402).json({
        error: "Payment required",
        price: "0.01 SEI",
        details: error.message,
      });
    },
  })
);
```

## Complete Example

```typescript
import express from "express";
import { createFacilitator } from "@x402/facilitator";
import { x402Middleware } from "@x402/express";

const app = express();
app.use(express.json());

const facilitator = createFacilitator({
  network: "sei-mainnet",
  privateKey: process.env.FACILITATOR_PRIVATE_KEY,
});

// Free tier
app.get("/api/public/status", (req, res) => {
  res.json({ status: "API is running" });
});

// Paid tier - Basic AI
app.use(
  "/api/ai/basic",
  x402Middleware(facilitator, {
    price: "0.01",
  })
);

app.post("/api/ai/basic/generate", (req, res) => {
  const { prompt } = req.body;
  res.json({
    result: `AI response for: ${prompt}`,
    model: "basic",
  });
});

// Paid tier - Advanced AI
app.use(
  "/api/ai/advanced",
  x402Middleware(facilitator, {
    price: "0.05",
  })
);

app.post("/api/ai/advanced/generate", (req, res) => {
  const { prompt } = req.body;
  res.json({
    result: `Advanced AI response for: ${prompt}`,
    model: "gpt-4",
  });
});

app.listen(3000);
```

## Testing Your Server

Start your server and test with curl:

```bash
# This will return 402 Payment Required
curl http://localhost:3000/api/premium/data

# With payment header (use x402 client to generate)
curl -H "x-402-payment: <payment_data>" \
     http://localhost:3000/api/premium/data
```

## Environment Variables

Create a `.env` file:

```env
FACILITATOR_PRIVATE_KEY=your_sei_private_key_here
PORT=3000
```
