## Prerequisites

Before setting up a facilitator, ensure you have:

- **Node.js 18+** installed
- **Sei wallet** with some SEI for gas fees
- **Private key** for your facilitator wallet

## Quick Setup

### 1. Install Dependencies

```bash
npm install @sei-js/x402-facilitator
```

### 2. Environment Configuration

Create a `.env` file:

```env
# Required: Your facilitator private key
FACILITATOR_PRIVATE_KEY=your_private_key_here

# Optional: Network configuration
SEI_NETWORK=sei-mainnet
SEI_RPC_URL=https://evm-rpc.sei-apis.com

# Optional: Server configuration
PORT=3000
NODE_ENV=production
```

### 3. Basic Facilitator

```typescript
import { createFacilitator } from "@sei-js/x402-facilitator";

const facilitator = createFacilitator({
  network: process.env.SEI_NETWORK || "sei-mainnet",
  privateKey: process.env.FACILITATOR_PRIVATE_KEY,
});

// Test the setup
async function testSetup() {
  try {
    const address = await facilitator.getAddress();
    console.log("Facilitator address:", address);

    const balance = await facilitator.getBalance();
    console.log("Balance:", balance, "SEI");
  } catch (error) {
    console.error("Setup failed:", error);
  }
}

testSetup();
```

## Configuration Options

### Network Settings

```typescript
const facilitator = createFacilitator({
  // Network selection
  network: "sei-mainnet", // or 'sei-testnet'

  // Custom RPC (optional)
  rpcUrl: "https://evm-rpc.sei-apis.com",

  // Private key
  privateKey: process.env.FACILITATOR_PRIVATE_KEY,
});
```

### Pricing Configuration

```typescript
const facilitator = createFacilitator({
  network: "sei-mainnet",
  privateKey: process.env.FACILITATOR_PRIVATE_KEY,

  // Default pricing
  defaultPrice: {
    amount: "0.01",
    currency: "SEI",
  },

  // Payment validation timeout
  timeout: 30000, // 30 seconds
});
```

### Gas Settings

```typescript
const facilitator = createFacilitator({
  network: "sei-mainnet",
  privateKey: process.env.FACILITATOR_PRIVATE_KEY,

  // Gas configuration
  gasSettings: {
    gasLimit: 100000,
    gasPrice: "1000000000", // 1 gwei
  },
});
```

## Production Setup

### 1. Secure Key Management

```typescript
// ❌ Don't hardcode private keys
const facilitator = createFacilitator({
  privateKey: "0x123...", // NEVER DO THIS
});

// ✅ Use environment variables
const facilitator = createFacilitator({
  privateKey: process.env.FACILITATOR_PRIVATE_KEY,
});

// ✅ Use AWS Secrets Manager
import { getSecret } from "@aws-sdk/client-secrets-manager";
const privateKey = await getSecret("facilitator-key");
```

### 2. Error Handling

```typescript
const facilitator = createFacilitator({
  network: "sei-mainnet",
  privateKey: process.env.FACILITATOR_PRIVATE_KEY,

  // Error handling
  onError: (error) => {
    console.error("Facilitator error:", error);
    // Send to monitoring service
  },

  // Retry configuration
  retries: 3,
  retryDelay: 1000,
});
```

### 3. Monitoring

```typescript
// Monitor facilitator health
async function healthCheck() {
  try {
    const balance = await facilitator.getBalance();

    if (balance < 0.1) {
      console.warn("Low balance warning:", balance, "SEI");
      // Alert admin
    }

    return { status: "healthy", balance };
  } catch (error) {
    console.error("Health check failed:", error);
    return { status: "unhealthy", error: error.message };
  }
}

// Run health check every 5 minutes
setInterval(healthCheck, 5 * 60 * 1000);
```

## Troubleshooting

### Common Issues

**Invalid private key**

```bash
Error: Invalid private key format
```

- Ensure private key starts with `0x`
- Check key length (64 characters + 0x prefix)

**Network connection failed**

```bash
Error: Network request failed
```

- Check internet connection
- Verify RPC URL is correct
- Try switching to different RPC endpoint

**Insufficient balance**

```bash
Error: Insufficient funds for gas
```

- Add SEI to your facilitator wallet
- Check gas price settings
