## Overview

x402 is an HTTP micropayment protocol that enables developers to monetize APIs, content, and services with seamless blockchain payments. Built with Sei Network integration, x402 allows for instant, low-cost payments directly in HTTP requests.

## Key Features

- **HTTP-native**: Payments are embedded directly in HTTP headers
- **Instant settlements**: Leverage Sei's 400ms finality for immediate payment confirmation
- **Low fees**: Perfect for micropayments with Sei's minimal transaction costs
- **Developer-friendly**: Simple integration with existing HTTP servers and clients

## How it Works

1. **Client** prepares a payment and includes it in the `x-402-payment` header
2. **Server** validates the payment on Sei Network
3. **Content** is served immediately upon successful payment verification
4. **Settlement** happens instantly on-chain

## Use Cases

- **Paid APIs**: Charge per API call or usage-based pricing
- **Premium Content**: Paywall articles, videos, or downloads
- **AI Services**: Monetize AI inference calls with micropayments
- **Data Feeds**: Real-time data access with per-request pricing
