## Common Use Cases

x402 protocol enables micropayments for various digital services. Here are the most popular implementations:

## AI API Monetization

Charge per AI inference call or by complexity:

```typescript
// Basic AI endpoint - 0.01 SEI per request
app.post(
  "/ai/basic",
  x402Middleware(facilitator, { price: "0.01" }),
  (req, res) => {
    const { prompt } = req.body;
    res.json({ result: generateBasicResponse(prompt) });
  }
);

// Advanced AI endpoint - 0.05 SEI per request
app.post(
  "/ai/gpt4",
  x402Middleware(facilitator, { price: "0.05" }),
  (req, res) => {
    const { prompt } = req.body;
    res.json({ result: generateGPT4Response(prompt) });
  }
);
```

## Premium Content Access

Paywall articles, videos, or downloads:

```typescript
// Premium article access
app.get(
  "/articles/:id/premium",
  x402Middleware(facilitator, { price: "0.001" }),
  (req, res) => {
    const article = getFullArticle(req.params.id);
    res.json({ article });
  }
);
```

## Real-time Data Feeds

Charge for live market data or API access:

```typescript
// Market data feed - 0.005 SEI per request
app.get(
  "/market/live/:symbol",
  x402Middleware(facilitator, { price: "0.005" }),
  (req, res) => {
    const liveData = getMarketData(req.params.symbol);
    res.json({ data: liveData, timestamp: Date.now() });
  }
);
```

## Usage-Based Pricing

Dynamic pricing based on usage or complexity:

```typescript
app.use(
  "/api/compute",
  x402Middleware(facilitator, {
    pricing: (req) => {
      const { operations } = req.body;
      const basePrice = 0.001;
      const price = basePrice * operations.length;
      return { amount: price.toString(), currency: "SEI" };
    },
  })
);
```

## File Downloads

Paid access to digital files:

```typescript
app.get(
  "/downloads/:fileId",
  x402Middleware(facilitator, { price: "0.1" }),
  (req, res) => {
    const filePath = getSecureFilePath(req.params.fileId);
    res.download(filePath);
  }
);
```

## Benefits by Use Case

### AI Services

- ✅ **Perfect for**: Per-inference pricing
- ✅ **Benefits**: Instant payments, global access
- ✅ **Example pricing**: $0.001-$0.10 per request

### Premium Content

- ✅ **Perfect for**: Micro-subscriptions, pay-per-article
- ✅ **Benefits**: No subscription management
- ✅ **Example pricing**: $0.01-$1.00 per piece

### Data APIs

- ✅ **Perfect for**: Real-time data, usage-based pricing
- ✅ **Benefits**: Low latency, high throughput
- ✅ **Example pricing**: $0.001-$0.01 per request

### Digital Downloads

- ✅ **Perfect for**: Software, media, documents
- ✅ **Benefits**: Instant access after payment
- ✅ **Example pricing**: $0.10-$10.00 per download
